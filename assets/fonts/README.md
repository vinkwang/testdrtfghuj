Place a pixel font file here so the app can load it locally.

Recommended font: "Press Start 2P" (or another pixel/bitmap font). Download a WOFF2 or WOFF file and name it:

  PressStart2P-Regular.woff2

Then the app will be able to reference it from `/assets/fonts/PressStart2P-Regular.woff2`.

If you want a different filename, update the @font-face src in `assets/index-Cs3s0Mpd.js` accordingly.

License note: Ensure the font's license allows bundling in your project. "Press Start 2P" is available via Google Fonts under the Open Font License (SIL OFL).
